# Swegon CASA for Home Assistant

Swegon CASA custom integration for Home Assistant.

# Features
- Configuration through the Home Assistant user interface
- Automatic discovery of available Swegon CASA devices
- Real-time updates through WebSocket
- Support for reading ventilation and indoor climate values
- Control of supported operating modes and settings
- Automatic reconnection if the connection is interrupted
- HACS-compatible installation
- Swedish and English translations

# Installation
The recommended installation method is through HACS using this repository as a custom repository.

You need CASA Smart Access module to make this integration to work: https://www.swegon.com/products/air-handling/air-handling-units/casa/casa-smart-access/
You also need setup an account on https://swegoncasa.io/ before you can start using the app.

This is an independent community integration and is not affiliated with or officially supported by Swegon.
